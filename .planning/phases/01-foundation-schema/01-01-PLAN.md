# Plan: 01-01 - Initialize Shopify Remix App

## Objective
Initialize the Shopify Remix app template and configure the base settings (proxy, scopes).

## Context
We are starting from an empty directory (with `.git` and `.planning`). We need to bootstrap the official Shopify Remix template.

## Requirements
- **FND-01**: Initialize Shopify Remix App with TypeScript.
- **FND-03**: Configure App Proxy for secure storefront submissions.

## Threat Model
- **Threat**: Insecure App Proxy configuration could expose internal APIs.
- **Mitigation**: Ensure the proxy subpath is specific and any backend routes verify the `shopify-hmac-sha256` or equivalent if possible (though Proxy verification is standard in Remix template).

## Tasks

<task wave="1">
  <action>
    Run the Shopify app creation command. Since we are already in the directory, we'll use:
    `npx create-shopify-app@latest --template remix --name "custom-form-builder" --path . --yes`
    Note: If it complains about existing files, we may need to manually move/re-add them or use a temporary folder and move contents back.
  </action>
  <read_first>

  </read_first>
  <acceptance_criteria>

    - `package.json` exists.

  </acceptance_criteria>
</task>

<task wave="2">
  <action>
    Update `shopify.app.toml` to include the App Proxy configuration and necessary scopes.
    Add:
    ```toml
    [access_scopes]
    # Add write_files to existing scopes
    scopes = "write_products,write_files"

    [[proxies]]
    url = "/apps/custom-form-builder"
    subpath = "submit"
    prefix = "apps"
    ```
  </action>
  <read_first>
    - shopify.app.toml
  </read_first>
  <acceptance_criteria>
    - `shopify.app.toml` contains `write_files`.
    - `shopify.app.toml` contains the `[[proxies]]` block with correct values.
  </acceptance_criteria>
</task>
